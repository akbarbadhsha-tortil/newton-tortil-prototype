# Newton Cinema × Tortil — Application Journey Prototype

Interactive prototype of the Newton Cinema contact page and the four "Your Next Step" journeys
(Start a New Project, Join as Cast, Join as Crew, Careers at Newton) handing off to Tortil.

**Demo mode.** The Tortil screens are a local simulation. Nothing you enter is sent to Tortil
or any other server; drafts stay in your browser. Use **Reset demo** in the gold banner to clear them.

## Try it

1. Scroll to **Your Next Step** and click any card.
2. Continue → sign up with **Fill with demo details** and code **246810**
   (or **Log in → Use demo account**).
3. Complete the form, review, and submit to see the confirmation.

Prototype for review only — not the live Newton Cinema website or the live Tortil app.
